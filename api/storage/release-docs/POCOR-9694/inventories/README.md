# POCOR-9694 — Inventories

Two read-only audits produced during the POCOR-9694 review. They are the source-of-truth inputs to the **v6 transition backlog** — every line in `exec-callsites.csv` and every `live` row in `legacy-shells-inventory.csv` corresponds to a follow-up ticket in the v6 cycle.

Both files are deliberately **CSV** so they can be pasted into spreadsheets, sorted, filtered, and assigned without losing structure.

## `exec-callsites.csv`

Every `exec()`, `shell_exec()`, `proc_open()`, and `passthru()` call in non-vendor PHP code, with a proposed replacement strategy.

| Column | Meaning |
|---|---|
| `file` | Path relative to repo root |
| `line` | Line number of the call |
| `function` | One of: `exec` / `shell_exec` / `proc_open` / `passthru` |
| `context_snippet` | 60-char excerpt (commas escaped as `;`) |
| `proposed_replacement` | One of: `laravel-scheduler` / `system_processes-row` / `delete-with-shell` / `keep-cli-only` |

**Totals:** 127 callsites — `plugins/` 98 · `src/` 25 · `api/` 4 · `config/` & `webroot/` 0.

**Replacement breakdown:** `system_processes-row` 92 · `keep-cli-only` 20 · `delete-with-shell` 9 · `laravel-scheduler` 6.

**Security findings flagged during the audit:**

1. `src/Shell/DatabaseSqlDumpShell.php:29` — `mysqldump` shell-string built from unescaped DB config values. Slated for `delete-with-shell`.
2. `plugins/Cache/src/Controller/CachesController.php:46` — `exec('git pull')` reachable over HTTP when `Configure::read('debug')` is true. Slated for `laravel-scheduler`.
3. `plugins/Installer/src/Form/DatabaseConnectionForm.php:402-403` — commented-out unescaped `mysql` shell-out. Dead code, exemplar of the anti-pattern; remove during v6 cleanup.

## `legacy-shells-inventory.csv`

Every `src/Shell/*.php` file (CakePHP 3.x shells extending the deprecated `Cake\Console\Shell`).

| Column | Meaning |
|---|---|
| `file` | Path relative to repo root |
| `classname` | PHP class name |
| `extends` | Base class (`Cake\Console\Shell` is the deprecated marker) |
| `classification` | `live` / `dead` / `superseded` |
| `laravel_equivalent` | Path to the Laravel command if `superseded` |
| `notes` | 80-char description (commas escaped as `;`) |

**Totals:** 73 shells — `live` 24 · `dead` 30 · `superseded` 19.

The 30 `dead` shells are deletable today (no callers anywhere outside `src/Shell/`). The 19 `superseded` shells are deletable once the regression matrix on their Laravel equivalents passes. The 24 `live` shells are the v6-cycle migration backlog.
